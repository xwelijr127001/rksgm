# Raksa Investigator · series completion design · 2026-11-21

Proposed, awaiting owner decision. Keep the staff training story primary and the event QR at `/investigator`. Three playable files should teach three different judgments: a mistaken witness, an evidenced coverage mismatch, and deliberate inflation of one item. Personal scores already accumulate across the first two cases. The missing rewards are a third investigation, attainable senior ranks, and an optional shared event board.

## Case 3 · Satu Baris Terlalu Banyak

Use an entirely invented composite. No source case scans, brands, identifiable dates, addresses or real people. Target five minutes on a phone. The guest is reviewing an estimate for bumper and mirror damage after a parking incident. Opening hunch: “Apakah kedua bagian rusak pada kejadian yang sama?” The bumper damage is corroborated. An old mirror defect could have been included by mistake. The person submitting the estimate gets to explain and correct it.

This panel simulates evidence review. No binding award, courtroom powers or claim of formal mediation. Use the scripted chair question “Apa yang bisa kita simpulkan dari bukti ini?” Give parties a correction and response before the recommendation. [konfirmasi PIC] terminology, authority, consent for illustrative evidence, handling of the undisputed item, investigation and review channels, all public-language variants. No automatic payment, refusal, criminal determination or public accusation. Full-credit example: “Terima kasih sudah menjelaskan. Saya akan mencatat kerusakan bumper dan meminta tim berwenang menelaah bagian spion. Bapak bisa menambahkan keterangan.” Partial: seek clarification without recording or routing the discrepancy. Zero: pronounce the whole claim fraudulent. The message score separately measures respectful explanation, reason and next step. Preserve Case 2’s existing PIC gate.

## Press, present, recover

Add an optional **Tanya lebih lanjut** to one existing witness in each earlier case and to both Case 3 statements. One authored question and response per press, marked with its source in the notebook. For example, ask the toll officer whether the lane was personally observed; ask Yusuf when the trip record was closed. In Case 3 ask when the photo was taken and who confirmed the message. The response supplies context. All required proof remains available on the standard path. Pressing costs zero points, has no timer, and can be reread. Expose the same control to keyboard and screen readers. Use tap-to-enlarge, 44 px controls, reduced-motion support and ID/EN/ZH throughout. An interrupted press returns to the same statement with its earned note.

Keep earlier cases’ single confrontation, scores, replay and saved node IDs. Only Case 3 receives the panel. Each miss explains the chosen card’s limits, the second miss enables guided presentation. Never restart round 1 after round 2. For the two-round evidence award, each round earns 20 first try, 12 second try, or 5 guided; verdict and handling each contribute up to 30. Previous single-round awards remain 40/25/10. Retain S/A/B/C thresholds. Practice repeats the weakest round or choice and changes neither personal best nor event score.

## Reachable rewards

Ship three cases. A fourth made solely to reach a title delays the reward and adds another content approval. Keep existing progression through Senior: zero stamps = Muda; one or two = Investigator; three = Senior. Kepala requires all three stamps and combined personal best ≥255/300. A guest meeting both milestones at once receives the Senior seal and the Kepala frame together. No score decay. Existing two-case records retain scores, stamps and title when the denominator expands to 300.

One unique completion unlocks the case’s corrected file in a read-only archive. Second stamp gives a two-case badge. Third gives the panel seal. Kepala adds the officer-card frame. Archive the chosen explanation with its best run; for older saves without a recorded choice show the factual case summary. Every result shows this run, best, series total and *one* reachable next action: next unfinished file, replay the case with most recoverable points, or open the completed archive. Ties use case order. No locked Case 4 tile. Solo stays playable offline with existing storage fallback.

## Event board · Top Investigator hari ini

At an event the staffed host opens a dedicated Investigator session in the existing event host surface. The projector shows a join QR `/investigator?acara=CODE`. A walk-up player may also enter that public code in the hub. Show separate choices “Ikut papan acara” and “Main sendiri”. Joining starts an event run from the beginning, while preserving existing solo saves. Clearly label public display and expiry. Generate an event-local alias, e.g. “Lensa 042”; allow reroll before first play. Collect no real names, contact details or free text. Separate fresh-guest handoff from resume.

Use the existing Express/SQLite and transport security patterns. Isolate event runs from quiz phases, answer tables, prize logic and local score imports. Scope the board to one host session and Asia/Jakarta calendar day. Close at local midnight or host closure. Return top ten aliases, best-of-each-case sum and stamp count; equal totals share rank. Host sees participation count, ranked aliases and moderation controls to hide an entry, close and clear. Phones see their own standing. Projector gets a read-only snapshot on a short polling interval. A restart restores the open board from SQLite; reconnect resumes the same run. Purge board, runs and aliases within 24 hours after closure, including after downtime.

Server issues opaque expiring event participant and run credentials. Verify case, event, stage order, selected IDs and attempt count on each scored decision. Compute scores server-side with the same versioned rubric as solo. Transactionally store one best per participant/case and one completion per run. Retried commands return the same acknowledgement. Never accept submitted totals, grades, stamps or device history. Network loss pauses ranked decisions with retry or an explicit switch to unranked play. Shared QR alone gives no host privileges. Require staff hostRooms and event ownership for moderation; scoped read-only projector credential and participant credentials travel in headers, never query strings. Reuse trusted-hop IP handling, approved origins, bounded request bodies and redacted logs. Rate limits: joins 120/minute per trusted IP and 300/minute per board (shared Wi-Fi), decisions 30/minute per participant, host mutations 20/minute per host. Bound limiter state and cap each board at 500 participants. Booth recognition only: alias resets and prior knowledge remain possible; offer no valuable prizes on this assurance level.

Fix pacing if three stall at one step; change the event door if ≥5/8 prefer Dev after trying both. Address a repeated stall or door failure before interpreting expansion as validated. Mixed results call for another round. Record counts, not population claims. Product gates are reachable features and approved scripts.
