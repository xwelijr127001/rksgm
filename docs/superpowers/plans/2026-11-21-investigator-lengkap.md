## 1 · Fullstack · contracts and compatible scoring

Own `shared/investigator/{rubric,event}.ts`, `client/src/cerita/tipe.ts`, `investigasi/{status,skor}.ts`. Publish these interfaces first:

- `Press = {id, questionKey, answerKey}` on a statement, optional. `Round = {id, statementId, promptKey, evidenceIds, acceptedIds, hintKeys, correctionKey}`. Stable string IDs; locale keys resolve per episode. Optional `panel.rounds` on KonfigInvestigasi. Add panel nodes carrying round ID and attempt. Preserve legacy evidence and witness IDs, node names and flag readers. Extend permitted actors/cards and verdict labels for Case 3. Use `tambahan` internally for the referral action, with a case-specific visible label (“Teruskan untuk pemeriksaan”); decision concerns an evidenced intentional addition. Earlier labels and tables keep their values.
- Pure shared rubric `score(caseId, rubricVersion, roundOutcomes[], verdictId, messageId) -> {bukti,putusan,penanganan,total,nilai}`. Outcomes are first/second/guided in authored round order. Shared case manifests supply allowed card/decision IDs, accepted cards and weights. Widen evidence subtotal from the existing literal union. Adapt local `skorKasus` and practice helpers; preserve existing callers’ results. Use flag `panel:<roundId>:<outcome>` and `press:<statementId>:<pressId>`; unmodified legacy saves use existing `keb:*`.
- Freeze HTTP types for card 4: create/join/start; `Decision = {runId,seq,commandId,stageId,choiceId}`; `Ack = {seq,nextStage,status,score?}`; public row `{rank,alias,total,stamps}`. Include shared case/rubric version in run creation reply. Unknown version disables ranked play with a solo exit. Freeze UI props for card 3: `PressPanel({question,answer,opened,onPress,onClose})`, `PanelRound({chair,statement,cards,attempt,onInspect,onPresent})` using translated text and evidence IDs. Return selections, never mutate scores in UI components.

## 4 · Fullstack · event service (after 1; parallel with 2 and 3)

Own `server/src/investigator/**` and registration in `server/src/index.ts`. Use existing staff-session authentication, hostRooms capability, origin/proxy policy and SQLite migration conventions. Mount `/api/investigator/events`. Staff create; owner-only endpoints close, hide, clear and issue a revocable projector credential. Public code joins issue random alias and hashed bearer credential; run creation binds participant, case, board and rubric version. POST ordered decisions under the participant bearer; validate server-owned current stage and apply shared scorer. Guided retries and practice have distinct semantics: practice never submits. UNIQUE(runId,commandId) plus stored request digest and response handles retries; conflicting reuse is rejected. In one transaction advance stage, record result and upsert best. Include authenticated run-resume and participant standing, read-only projector snapshot, expiry cleanup and limits from design. No client totals or quiz-room state mutation.
